# COLLECTION-MANIPULATER

## Introduction
The Student Data Organizer is a menu-driven Python project used to manage student information. It allows users to add, display, update, and delete student records.

## Features
1. **Add Student:** Enter student ID, name, age, grade, date of birth, and subjects.
2. **Display All Students:** Display all student details in a formatted way.
3. **Update Student Information:** Update student ID, name, age, grade, or subjects.
4. **Delete Student:** Delete a student record using the student ID.
5. **Display Subjects Offered:** Display all unique subjects offered by students.
6. **Exit:** Exit the program.

## Concepts Used
- Lists
- Tuples
- Sets
- Dictionaries
- While loop
- For loop
- If-elif-else statements
- String methods
- f-strings
- Type casting
- `del` keyword

## How to Run
1. Install Python 3 on your computer.
2. Save the code as `student_data_organizer.py`.
3. Open the terminal in the folder where the file is saved.
4. Run the following command:

   ```bash
   python student_data_organizer.py
   ```

5. Select an option from the menu and follow the instructions.

## Data Storage
The program stores student records in a list of dictionaries.

- **Tuple:** Stores the student ID and date of birth.
- **Set:** Stores unique subjects for each student.
- **Dictionary:** Stores student details.
- **List:** Stores all student records.

The data is stored temporarily while the program is running.
